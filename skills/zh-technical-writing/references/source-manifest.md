## Duplicate and version decisions

No byte-exact duplicates were found. Closely related TCloud files were treated as publication or revision variants of their matching canonical articles. The current `new-typescript-project` README and the older TypeScript project article describe the same project workflow, so they share one normalized example; the newer, more complete README is the style anchor. The four Bootstrap Blueprints lessons were retained as separate canonical examples because each teaches a distinct component or page-building workflow. The `layer-esm` article remains a distinct product-guide example rather than being merged with the structurally similar `scp-next` guide because it covers a different tool, workflow, and migration path. The supplied `scp-next` and macOS `scutil` articles refresh existing canonical sources; the broader `scutil` evidence materially updates its characterization. The English-only `vue-screenfull` README remains a distinct product-guide example rather than being merged with the existing HTML5 Fullscreen API article. Standard content declarations and publishing wrappers were not extracted as style. The Docker errors, Workbox configuration, and webpack multi-configuration English/Chinese pairs were consolidated into one normalized example per pair; the Chinese article is the style anchor and the English article supplies translation-structure evidence. Metadata-only and embedded-media files were not curated.
