# React documentation profile

- Profile: React documentation
- Role: Optional React ecosystem profile
- Applies to: React tutorials, concepts, libraries, Hooks, components, migrations, examples, and relevant ecosystem READMEs
- Last reviewed: 2026-07-30
- Source type: Official ecosystem documentation
- Endorsement: None; this skill independently interprets observed patterns

See [../source-manifest.md](../source-manifest.md) for page-level provenance.

## Observed React patterns

- Learning pages often begin with a reader goal and learning outcomes.
- Explanations introduce a concrete problem before a broader abstraction.
- Examples build incrementally and show visible results.
- Conceptual teaching and API reference use distinct structures.
- Pitfalls, notes, deep dives, recaps, and challenges appear selectively.
- Current examples favor function components, JSX, and Hooks, while reference pages retain legacy context.

These are observations, not claims that every React document must use the pattern.

## Recommended profile rules

- Start with the reader's concrete UI or library goal.
- State what readers will learn when the tutorial covers multiple concepts.
- Begin with the smallest useful, focused, runnable example.
- Add concepts incrementally and explain why each important change works.
- Prefer a problem, simple attempt, limitation, idiomatic solution, and verified result sequence when it aids learning.
- Explain a useful mental model and connect it to observable behavior.
- Put common pitfalls near the code or concept that triggers them.
- Separate conceptual teaching from API reference.
- Preserve idiomatic React terminology and capitalization.
- Default to modern function components and Hooks.
- Preserve class-component or legacy conventions when the target project uses them.
- Do not imply that JSX is required to use React.

## Optional stylistic tendencies

Finished previews, editable sandboxes, emojis, encouraging asides, collapsible deep dives, recaps, and extra challenges are optional. Use them only when the publishing system supports them and they improve learning.

## Boundaries

Do not apply this profile to unrelated ecosystems, release notes, or short API lookup pages. Google and Microsoft layers remain active below the profile. Do not copy distinctive React prose or full source examples.
